Shared store — Google Sheet

      
Paste the Google Apps Script Web App URL for your shared sheet. When it is set, teacher submissions and student reports go to that Sheet and the dashboard reads from it (GET returns drillStatus, classes, teacher, students). Until then the app stays in Demo — not shared yet mode and never claims entries are shared.

      

      

        
        
        
      

      
Status: Demo — not shared yet

      

      
Set up the Sheet (one time, sheet owner only)

      
    
        
  1. Create a Google Sheet. Tabs are created by the script if missing: Classes (Class, Total, NoClass, Note, AssemblyPoint), TeacherSubmissions, StudentReports, DrillStatus.
    2. 
        
  2. Extensions → Apps Script, paste the bridge script below (same as fire-drill-shared/Code.gs), Save.
    3. 
        
  3. Deploy → New deployment → Web app → Execute as: Me, Who has access: Anyone → Deploy, copy the Web App URL ending in /exec.
    4. 
        
  4. Paste that URL above and tap Connect. The banner should change to “Shared — connected to Google Sheet”. Student link: same app link + ?view=student (add &backend=URL if you bookmark it that way).
    5. 
      

      
      
Bridge contract (full script is in fire-drill-shared/Code.gs):
POST {type:"teacher", className, total, present, submittedBy}
POST {type:"student", name, className, status:"safe|inside|need_help",
      assemblyPoint, building, floor, room, note, lat, lng, accuracy}
POST {type:"status", status}
GET  -> {drillStatus, classes:[], teacher:[], students:[]}
Sheet tabs: Classes | TeacherSubmissions | StudentReports | DrillStatus
Deploy as Web app, Execute as Me, Access: Anyone, then paste the /exec URL above.

      
This setting is kept in this browser session only in this static app — paste the URL again after a reload, or add it as ?backend=YOUR_URL to your bookmarked link. No data is sent anywhere in demo mode.

    

    

      
Privacy & data collected

      
Only: class, count, student name (self-report only), status, assembly point / building-floor-room, optional one-time location, note, and time. No continuous tracking. No location history. Only staff should open the Coordinator view — students see only their own confirmation and the general drill status.
